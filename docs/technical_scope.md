# Technical Scope

Asuna ML Agent is designed as a machine learning workflow assistant.

## Included Scope

- Applied ML project guidance
- Classification and regression workflow concepts
- Dataset validation
- Leakage detection concepts
- Model comparison
- Scoring workflow design
- Drift awareness
- What-if analysis
- ROI-oriented interpretation
- Prescriptive analytics concepts

## Excluded Scope

- General chatbot behavior
- Desktop automation
- Game development
- Frontend generation
- Personal assistant behavior
- Production MLOps deployment
- Cloud infrastructure automation

## Intended Use

This project is intended for technical learning, ML workflow design, portfolio demonstration, and business analytics experimentation.
