# Command Reference

## Project Commands

| Command | Purpose |
|---|---|
| `/project` | Create or select an ML project context. |
| `/load` | Load a dataset into the active project. |
| `/target` | Define the prediction target. |
| `/date` | Define or inspect temporal columns. |

## Validation Commands

| Command | Purpose |
|---|---|
| `/leakage` | Review potential leakage risks. |
| `/results` | Inspect generated outputs. |
| `/explain` | Explain model behavior and project findings. |

## Training Commands

| Command | Purpose |
|---|---|
| `/train` | Run model training workflow. |
| `/run` | Execute a controlled ML run. |
| `/runs` | List historical model runs. |
| `/activate-run` | Select a previous run as active. |
| `/compare` | Compare model runs. |

## Business Commands

| Command | Purpose |
|---|---|
| `/score` | Score new cases. |
| `/whatif` | Simulate feature changes and expected impact. |
| `/history` | Review score history. |
| `/roi` | Estimate business impact. |
| `/prescribe` | Generate action-oriented recommendations. |
| `/executive` | Produce an executive-level summary. |
